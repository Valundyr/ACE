Dice Simulator from D4 to D20

This is a little project that me and my friend made to simulate a rolling dice launcher. 
The project consist off one bread board, one raspberry pi pico w (one without Wifi is good as well), a MPU6500, an OLED display, 3 buttons, 3 resistors of 20 KOmhs and jumpers to connect everything.

The program can be seen in the in the folder above, we made use of 6 Finite state machines and used some Adafruit libraries to draw the menu and the dices. For any doubts and how teh code works you can always contact me here on git hub.
