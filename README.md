# Dice Simulator from D4 to D20

### This is a little project that me and my friend made to simulate a rolling dice launcher. 

The project consist of:
- one breadboard
- one raspberry pi pico w (one without Wifi is good as well)
- MPU6500
- OLED display
- 3 buttons
- 3 resistors of 20 K &Omega;
- jumpers to connect everything.

The program can be seen in the folder above, we made use of 6 Finite state machines and used some Adafruit libraries to draw the menu and the dices. For any doubts of how the code works you can always contact me here on git hub.

have fun testing it out 😁
